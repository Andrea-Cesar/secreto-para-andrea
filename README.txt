2. Sube index.html a la raíz del repositorio.
3. En Settings > Pages, elige Deploy from a branch, rama main y carpeta /(root), y guarda.
4. El enlace esperado si el usuario sigue siendo andrea-cesar será https://andrea-cesar.github.io/secreto-para-andrea/
5. Comparte el enlace solo con las personas invitadas a participar. GitHub Pages es público: no es una página protegida con contraseña. La etiqueta noindex solo solicita a buscadores no indexarla.
